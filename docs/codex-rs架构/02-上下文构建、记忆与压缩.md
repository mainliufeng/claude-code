# Codex Rust: 上下文构建、记忆与压缩

这一层负责：

- 维护线程历史
- 把历史规范化成模型可发送输入
- 注入 user instructions / skills
- 在上下文过长时做 compact 和 truncate

## 1. 文件拆分

- `core/src/context_manager/history.rs`
- `core/src/context_manager/normalize.rs`
- `core/src/state/session.rs`
- `core/src/compact.rs`
- `core/src/compact_remote.rs`
- `core/src/truncate.rs`
- `core/src/user_instructions.rs`
- `core/src/skills/injection.rs`

## 2. `ContextManager` 是这一层的核心

Claude Code 用的是消息历史 + attachments + compact boundary 组合；  
Codex Rust 更集中，核心是 `ContextManager`。

它负责：

- `record_items(...)`
- `for_prompt()`
- `normalize_history()`
- `replace(...)`
- `drop_last_n_user_turns(...)`
- token usage 估算和维护

也就是说，在 Codex Rust 里：

- 历史管理
- 历史规范化
- 历史裁剪

是更集中地收敛在 `ContextManager` 上的。

## 3. `SessionState` 的作用

`core/src/state/session.rs` 里，`SessionState` 主要持有：

- `session_configuration`
- `history: ContextManager`
- `latest_rate_limits`

和 Claude Code 相比，它这层更克制：

- 把“上下文历史”放到专门的 `ContextManager`
- `SessionState` 本身只做 session-scoped mutable state

不像 Claude Code 的 AppState 那样挂很多 UI/插件/MCP 状态。

## 4. user instructions 和 skills 是怎么注入的

`core/src/user_instructions.rs` 里：

- `UserInstructions` 会被编码成 `ResponseItem::Message`
- 文本格式是 `# AGENTS.md instructions for ...`

`core/src/skills/injection.rs` 里：

- `build_skill_injections(...)` 会找显式提及的 skill
- 读取 skill 文件内容
- 直接转成 `SkillInstructions`
- 最终也转成 `ResponseItem::Message`

这和 Claude Code 有一个关键区别：

- Claude Code 会先大量注入 `skill_listing / skill_discovery`
- Codex Rust 更偏“只有显式选中的 skill 才直接注入正文”

## 5. compact 是怎么做的

`core/src/compact.rs` 里，compact 的思路是：

- 发起一个 compact 任务
- 让模型基于 compact prompt 生成摘要
- 收集用户消息
- 重新构造 compact 后的 replacement history
- 替换 session history

也就是说，Codex Rust 的 compact 更接近：

- 一次显式的“历史重写”

而不是像 Claude Code 那样分成：

- tool result budget
- microcompact
- full compact
- post-compact restore

## 6. 这层和 Claude Code 的主要差异

### 6.1 相同点

- 都会把 skill / instructions 变成模型可见消息
- 都会在历史过长时做 compact
- 都需要历史规范化，防止 tool call/output 不一致

### 6.2 不同点

- Codex Rust 的历史控制更集中在 `ContextManager`
- Codex Rust 的 skill 注入更显式、更直接
- Codex Rust 没有 Claude Code 那么重的 attachment 体系
- Codex Rust 的 compact 更像“重建历史”，Claude Code 更像“多阶段增量收缩”

## 7. 一句话总结

Codex Rust 这一层的风格是：

- 少做一层通用 attachment 桥接
- 更直接地把 history / skill instructions / compact 都收敛到 `ResponseItem` 历史上
